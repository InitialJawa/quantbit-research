## Insight Utama

### Target User Segments:
1. **Pemula (60%)** — butuh edukasi + guidance
2. **Intermediate (30%)** — butuh tool + tracking
3. **Advanced (10%)** — butuh analysis + backtest

### Key Features dari TikTok Data:
1. **Edukasi** — 80% user mau belajar
2. **Tracking** — 70% user mau track portofolio
3. **Auto-invest** — 50% user mau auto-invest
4. **Mentor** — 40% user butuh guidance
5. **Simulasi** — 30% user mau test dulu

### Push Back Potensial:
- **Asumsi "AI auto-decision"** → TikTok bilang user skeptis, mau AI untuk education & guidance, bukan auto-decision
- **Asumsi "Terminal UI"** → TikTok user (terutama pemula) mau UI yang familiar, bukan terminal aesthetic
- **Asumsi "Fitur kompleks"** → 70% user pemula mau simple, gak perlu fitur 50+
