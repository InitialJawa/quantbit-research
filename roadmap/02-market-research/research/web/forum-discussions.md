## SWOT Analysis (dari data forum)

### Strengths (Yang Sudah Ada)
- **Excel template** — Gratis, fleksibel, familiar
- **Broker app** — Real-time data, auto-update
- **Manual tracking** — Murah, gak perlu app

### Weaknesses (Yang Bisa Diperbaiki)
- **Manual input** — Ribet, error-prone
- **Fragmented data** — Data di banyak app
- **No guidance** — Pemula bingung
- **No backtest** — Gak bisa test strategy

### Opportunities (Yang Bisa Dibuat)
- **Auto-import** — Dari broker, bank, Excel
- **AI assistant** — Q&A & explanation
- **Edukasi** — Untuk pemula
- **Backtest engine** — Test strategy dulu

### Threats (Yang Harus Diwaspadai)
- **Competitor apps** — Sudah banyak
- **Excel** — Gratis dan familiar
- **Broker app** — Sudah punya fitur tracking
- **AI skepticism** — User skeptis AI finance

## Insight Utama

### User Persona 1: Pemula (60% forum threads)
- **Profile**: Usia 18-30, modal < 10 juta
- **Pain Points**:
  - Gak tau harus mulai dari mana
  - Butuh guidance/mentor
  - Mau simulasi dulu
- **Preferred Solution**:
  - Simple UI
  - Edukasi built-in
  - AI untuk Q&A & explanation
  - Simulasi/backtest

### User Persona 2: Intermediate (30% forum threads)
- **Profile**: Usia 25-45, modal 10-100 juta
- **Pain Points**:
  - Ribet input manual
  - Data fragmented
  - Gak tau harus rebalance gimana
- **Preferred Solution**:
  - Auto-import dari broker
  - Real-time price
  - Backtest engine
  - Auto-rebalance

### User Persona 3: Advanced (10% forum threads)
- **Profile**: Usia 30+, modal > 100 juta
- **Pain Points**:
  - Gak tau strategy mana yang terbaik
  - Butuh analysis mendalam
  - Mau test multiple strategies
- **Preferred Solution**:
  - Advanced backtest
  - Multi-strategy comparison
  - AI untuk analysis & explanation
  - Custom scoring

## Kesimpulan

### Must-Have Features (dari data forum):
1. **Auto-import** — Dari broker, bank, atau Excel
2. **Real-time data** — Harga saham update otomatis
3. **Backtest engine** — Test strategy sebelum deploy
4. **AI assistant** — Q&A & explanation, bukan auto-decision
5. **Edukasi** — Untuk pemula

### Should-Have Features:
1. **Multi-account** — Gabung semua broker
2. **Rebalancing** — Auto atau manual
3. **Alert** — Saat harga turun/naik
4. **Export** — Ke Excel/CSV

### Nice-to-Have Features:
1. **Terminal aesthetic** — Mungkin terlalu complex
2. **Advanced AI** — Multi-provider
3. **WebSocket** — Real-time update

### Push Back dari Data:
- **Terminal aesthetic** — Forum bilang user mau UI familiar kayak Excel
- **Fitur 50+** — Forum bilang "yang penting simple"
- **AI auto-decision** — Forum bilang "skeptis AI finance"
- **Multi-tenant** — Forum bilang "untuk pemula, single-user cukup"
