## Pricing Insight

### Sweet Spot:
- **Gratis**: Untuk pemula & trial
- **Freemium (Rp 5-15K/bulan)**: Untuk advanced user
- **Annual discount (70% off)**: Untuk loyal user

### Value Proposition per Tier:

**Gratis (Must-Have)**:
- Real-time price
- Basic portfolio tracking
- Manual input
- Basic chart
- Community/forum

**Premium (Rp 5-15K/bulan)**:
- Auto-import dari broker
- Advanced chart
- Backtest engine
- AI assistant
- Multi-account aggregation
- Advanced analytics

**Enterprise (Rp 50K+/bulan)**:
- Custom integration
- API access
- White-label
- Dedicated support

## Pricing Strategy QuantBit V2

### Recommended:
1. **Gratis**:
   - Real-time price
   - Manual input
   - Basic portfolio tracking
   - Basic chart
   - Community

2. **Premium (Rp 9.9K/bulan)**:
   - Auto-import dari multiple brokers
   - Backtest engine
   - AI assistant (Q&A & explanation)
   - Advanced analytics
   - Multi-account aggregation
   - Priority support

3. **Annual Plan (Rp 99K/tahun)**:
   - 70% discount
   - All premium features
   - Exclusive content
   - Early access

### Push Back dari Data:
- **Premium terlalu mahal (>Rp 15K)** — User bilang "gak worth it"
- **Fitur terlalu banyak** — User mau simple, gak perlu 50 fitur
- **Auto-decision AI** — User skeptis, mau AI untuk Q&A & explanation
