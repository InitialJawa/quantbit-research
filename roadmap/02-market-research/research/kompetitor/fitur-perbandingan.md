## Kompetitor Langsung (Direct Competitors)

**Market Share**: 40%
**Pricing**: Freemium (Gratis + Premium Rp 9.9K/bulan)
**Target User**: Investor aktif

**Fitur**:
- ✅ Real-time price
- ✅ Chart (TradingView)
- ✅ News & analisis
- ✅ Community forum
- ✅ Portfolio tracking (manual input)

## Gap Analysis

### Fitur yang TIDAK ADA di Kompetitor:
1. **Auto-import dari multiple brokers** — Semua kompetitor hanya 1 broker atau manual
2. **AI untuk Q&A & explanation** — AI hanya untuk recommendation, bukan Q&A
3. **Backtest engine yang solid** — Hanya basic atau manual
4. **Auto-rebalancing** — Tidak ada yang auto-rebalance
5. **Multi-account aggregation** — Tidak ada yang gabung multiple broker

### Fitur yang SUDAH ADA dan Bagus:
1. **Real-time price** — Stockbit, Ajaib, Bibit
2. **Edukasi** — Ajaib, Bibit, Stockbit
3. **Chart** — Stockbit, MyStock
4. **Auto-invest (SIP)** — Ajaib, Bibit

## Opportunity

### White Space:
1. **Hybrid Solution**:
   - Auto-import dari multiple brokers
   - Manual input untuk yang gak punya broker
   - Excel import untuk yang pakai template

2. **AI Positioning**:
   - AI untuk Q&A & explanation (bukan auto-decision)
   - AI untuk recommendation (bukan auto-buy/auto-sell)
   - AI untuk education (untuk pemula)

3. **Backtest Engine**:
   - Solid backtest engine
   - Multi-strategy comparison
   - Golden test validation

4. **Simplicity**:
   - UI yang familiar (bukan terminal aesthetic untuk user biasa)
   - Simple workflow (bukan fitur 50+)
   - Auto-import + manual hybrid

## Competitive Advantage (QuantBit V2)

### USP:
1. **D1-backed, real-time scoring** — Engine server-side, bukan client-side
2. **AI Q&A & explanation** — Bukan auto-decision
3. **Solid backtest engine** — Golden test validation
4. **Auto-import hybrid** — Dari broker, bank, atau Excel
5. **Multi-account aggregation** — Gabung semua broker

### Weaknesses (yang harus dihindari):
1. **Terminal aesthetic** — User mau UI familiar
2. **Fitur 50+** — User mau simple
3. **Auto-decision AI** — User skeptis
4. **Single-broker only** — User mau multiple broker
